# RiGHoR

`RiGHoR` A Robust Statistical Framework for Detecting Celltype-specific gene expression alteration in Multi-sample Single-cell Studies.

## Installation

For the installation, the R package devtools is needed.

``` r
install.packages('devtools')
library(devtools)
```

RiGHoR can be installed by using devtools.

``` r
devtools::install_github("SChatLab/RiGHoR")
```
